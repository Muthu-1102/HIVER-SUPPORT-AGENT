# Hiver Customer Support Agent

AI customer-support agent built for the Hiver SDE Intern Assignment using the Customer Support on Twitter dataset.

## Project Structure

```
hiver-support-agent/
├── README.md
├── .gitignore
├── requirements.txt
├── src/
├── scripts/
├── data/
├── configs/
├── evaluation/
├── tests/
└── docs/
```

## Setup & Environment

1. Create & activate virtual environment:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Environment Status:
   - Python 3.10+
   - PyTorch / CUDA (RTX 2050) support
